# What each measure is:
# - bench: stage 1's workload (one connection, CREATE TABLE bench, 5000 INSERT OR REPLACE of
#   a 1 KB blob, then close), default settings. It builds the database the rest work on.
# - restore: a plain read-only restore of that database, for the restore's GET count.
# - stage3_costs takeover DIR: turso_durable::takeover_with_store into an empty DIR, with the
#   S3 store wrapped in a FaultStore that records every request. restore_* are the
#   TakeoverReport's RestoreReport; total_* count every request of the takeover, restore
#   included; each request follows as "request <op> <key>" (stat = HEAD, counted as a GET).
# - CLI takeover: the CLI's line, for a second takeover (over the first).
# - stage3_costs open DIR: open_with_store of a directory this writer owns; open_* are the
#   bucket_stats right after open returns (DURABLE_GC_AFTER_SEAL=off, so no GC thread
#   requests are mixed in); close_* the close's delta.
# - stage3_costs lease DIR PAUSE_MS: open, CREATE TABLE IF NOT EXISTS lease_cost, commit row 1;
#   then no_pause_* = the bucket_stats delta of commit 2, made right after; after_pause_* =
#   the delta of commit 3, made after sleeping PAUSE_MS (31 s; the default lease is 30 s).
#   DURABLE_GC_AFTER_SEAL=off for the same reason.
# - gc: the CLI's gc, first with the defaults (trim grace 10 min: every manifest too young),
#   then, 10 s later, with DURABLE_TRIM_GRACE_SECS=5 DURABLE_LEASE_MS=1000
#   DURABLE_RETRY_DEADLINE_MS=1000 DURABLE_REQUEST_TIMEOUT_MS=1000, whose minimum manifest age
#   is 5 + 1 + 1 + 1 = 8 s, twice. Then a restore + verify, and a count of the rows.
#

# the prefix and <T> were deleted afterwards):
#   DURABLE_PREFIX=<P> turso-durable bench --dir <T>/bench --commits 5000
#   DURABLE_PREFIX=<P> turso-durable restore --dir <T>/restored
#   DURABLE_PREFIX=<P> stage3_costs takeover <T>/took-ex           (run 2; run 1: second)
#   DURABLE_PREFIX=<P> turso-durable takeover --dir <T>/took       (run 2; run 1: first)
#   DURABLE_PREFIX=<P> DURABLE_GC_AFTER_SEAL=off stage3_costs open <T>/took    (twice)
#   DURABLE_PREFIX=<P> DURABLE_GC_AFTER_SEAL=off stage3_costs lease <T>/took 31000
